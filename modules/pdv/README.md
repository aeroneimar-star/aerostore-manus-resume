# PDV AEROSTORE — Stage 0

Fundação isolada do futuro módulo de PDV da AEROSTORE.

Objetivos desta fase:
- criar estrutura oficial do módulo;
- registrar rotas públicas `/pdv`;
- preparar base visual e arquitetural;
- manter o CRM atual intacto;
- não implementar vendas, fiscal, NFC-e, SAT ou TEF.

Princípios:
- operações assíncronas com loading e feedback visual;
- poucos cliques e navegação rápida;
- interface pronta para notebook, tablet e touch;
- pagamentos múltiplos na mesma venda;
- cashback separado do caixa;
- importações com preview, validação, confirmação, logs e rollback;
- registros importantes nunca devem ser apagados sem histórico.
